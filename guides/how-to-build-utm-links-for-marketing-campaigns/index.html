How to Build UTM Links for Marketing Campaigns

UTM parameters tell your analytics tool where a visit came from. A small naming decision made once can save hours of messy reporting later.

7 min read Updated November 5, 2026 TasklyTools guide

What UTM parameters do

A UTM parameter is a small piece of information added to the end of a URL. When someone clicks the link, analytics tools can record the source, medium, campaign, and other dimensions you defined. The parameters do not change the destination page by themselves.

UTM links are most useful when they follow a consistent system. If one post uses utm_source=instagram, another uses utm_source=Instagram, and a third uses utm_source=ig, your reports will treat them as separate sources.

The five common parameters

Standard UTM parameters
ParameterPurposeExample
utm_sourceThe platform or place the traffic comes from.newsletter, linkedin, partner_site
utm_mediumThe type of traffic or channel.email, social, referral
utm_campaignThe specific campaign or promotion.autumn_launch
utm_termPaid keyword or audience segment, when relevant.invoice_template
utm_contentThe creative variant or link placement.text_link, button_a

You do not need all five on every link. At minimum, use a source, medium, and campaign that make the report understandable. Add content or term when you genuinely need to compare variants.

Choose a naming convention

Write the convention down before the campaign starts. A simple standard is lowercase letters, numbers, and underscores or hyphens, used consistently.

  • Use lowercase everywhere. Avoid mixed case unless your analytics setup normalises it.
  • Separate words consistently. Pick underscores or hyphens and stick to them.
  • Use human-readable values. spring_launch is easier to audit than sl_2026_01.
  • Do not include personal data. Never put an email address, name, or client identifier in a UTM parameter.
  • Document the approved source and medium list. A short shared reference prevents duplicate variants.

Treat UTM values as public. They appear in URLs and may be shared, copied, or logged. Never use them for passwords, personal data, or confidential campaign details.

Build a UTM link

  1. Start with the final destination URL, including any required path.
  2. Check whether the URL already has query parameters. Add a ? if it does not, or an & if it already has one.
  3. Add each parameter as key=value. URL-encode spaces and special characters.
  4. Keep parameter order consistent with your team's convention.
  5. Open the finished link in a private window and confirm the destination page loads correctly.
  6. Record the final URL next to the campaign, channel, and publish date.

The UTM Builder handles the joining and encoding for you and rejects non-HTTP destinations.

A complete example

Suppose you are linking to the TasklyTools invoice guide from a newsletter. The destination is https://tasklytools.org/guides/how-to-create-a-professional-freelancer-invoice/.

Campaign URL

https://tasklytools.org/guides/how-to-create-a-professional-freelancer-invoice/?utm_source=newsletter&utm_medium=email&utm_campaign=november_tips&utm_content=invoice_guide_text_link

The report can now separate newsletter traffic from the same guide shared on social. If the newsletter has two link placements, the utm_content value lets you compare them without creating a second campaign.

Test before you publish

  • Destination URL is correct and loads without an error.
  • All required parameters are present and spelled consistently.
  • Existing query parameters were not accidentally replaced.
  • Values are lowercase and follow the documented separator style.
  • No personal, confidential, or sensitive information is in the URL.
  • Redirects preserve the parameters where you expect them to.
  • The link is stored in the campaign record for future reference.

Analytics takes time to populate. Do not assume a link is broken because a report has not updated immediately. Check the destination first, then review the analytics property after a reasonable delay.

Common mistakes

  • Changing naming styles mid-campaign. Reports fragment into near-duplicate sources.
  • Using the same source and medium for every channel. You lose the ability to compare performance.
  • Putting UTMs on internal links. This can overwrite the original attribution for a session.
  • Encoding the whole URL twice. The destination may receive broken values.
  • Using UTMs on links that already contain them. Duplicate parameters create unpredictable reporting.
  • Forgetting the campaign record. A link without context becomes impossible to audit later.
