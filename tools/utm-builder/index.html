How to use it

Build a campaign link in four steps

Consistent naming is the difference between useful campaign data and a crowded analytics report.

  1. Paste the full destination URL, including https://.
  2. Add the campaign source, medium, and campaign name. Required fields must be filled before a link is generated.
  3. Add the optional term and content values if you are tracking paid keywords or multiple ad variants.
  4. Copy the generated URL and use it as the destination in your email, ad, or social post.

Naming example

A newsletter link to a spring sale could use:

https://example.com/spring-sale?utm_source=newsletter&utm_medium=email&utm_campaign=spring_launch

Use the same naming pattern across campaigns so reports stay comparable.

Parameter guide

What each UTM parameter does

A quick reference for the five standard parameters this builder supports.

UTM parameters, whether they are required, and what they describe
Parameter Required here What it describes
utm_source Yes The platform or place sending traffic, such as newsletter, google, or linkedin.
utm_medium Yes The channel type, such as email, cpc, social, or referral.
utm_campaign Yes The campaign, launch, or promotion name.
utm_term No The paid search keyword that triggered the ad.
utm_content No The specific ad, button, or link variant in the same campaign.

This tool replaces existing UTM parameters on the destination URL instead of adding duplicate values. Other query parameters and the page anchor are kept.

FAQ

UTM Builder questions

Short answers about privacy, required fields, and link behavior.

What is a UTM builder?

A UTM builder adds standard campaign parameters to a destination URL so analytics platforms can identify the source, medium, and campaign that sent a visitor.

Is the UTM Builder free?

Yes. The TasklyTools UTM Builder is free to use and does not require an account.

Does this tool store my campaign data?

No. The link is built locally in your browser. Your destination URL and campaign details are not sent to a TasklyTools server.

Which UTM parameters are required?

This builder requires utm_source, utm_medium, and utm_campaign. utm_term and utm_content are optional.

Why are spaces encoded as %20?

Spaces are not valid in a URL query string, so they are percent-encoded as %20. Most analytics platforms read that correctly, but hyphens or underscores are easier to read in reports.

Can I edit or remove UTM parameters later?

Yes. You can rebuild the link with different values. If you rebuild a URL that already has UTM parameters, this tool replaces the existing UTM values instead of duplicating them.
